# Interface Par Emplacement

Instantanes du 8 octobre 2026 avant le retrait des emplacements dans les ecrans
actifs. Ils conservent les champs, colonnes et filtres de salle et bar, ainsi
que la presentation precedente de l'administration et de la caisse.

Ces fichiers ne sont pas importes par l'application. Les anciennes valeurs
de `tables.section` restent en base ; leur edition n'est plus proposee dans
le nouveau flux. Une modification de table ne doit pas les ecraser.

Les autres versions historiques du serveur, de la cuisine et du bar restent
dans le dossier parent. Voir `../../../FLUX_CAISSE.md` pour le flux actif.
